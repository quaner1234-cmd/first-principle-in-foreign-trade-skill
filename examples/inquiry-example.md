# Example — OEM 新询盘（LED 灯具，非服装）

> 脱敏构造案例。行业：消费电子配件 / LED 灯具 OEM。  
> 演示：新询盘如何先找最大阻塞，而不是立刻报价。

## 假设 Company Context（虚构）

- 工厂型 OEM，主做室内 LED 面板灯与灯条
- 常规 MOQ：1000 pcs / SKU
- 接受客户图纸开发；不自有面向 C 端品牌
- 认证：可协助 CE / RoHS 文件整理，但具体证书以实测与认证机构为准
- 未知字段保持 Unknown，不编造

## 输入

> Hello, we need LED panel lights for a hotel renovation project in the Middle East.  
> About 2,000 pcs, 60x60cm, 4000K. Please quote CIF Dubai best price ASAP.  
> We also need the lights to pass local fire safety requirements.

## 输出（Action Mode 摘要）

### 当前判断

**先澄清关键变量，不报 CIF。** 数量与尺寸方向有了，但光学/电气规格、认证边界、贸易条件细节不足；现在报的 CIF 不可信。

**项目阶段**：Qualified Inquiry（首次联系，但已有数量 + 基本规格 + 目标市场；不是需求尚粗的 New Lead。身份证据不足时仍应补公开背调。）

### 事实 / 推断 / 未知

**事实**
- 约 2000 pcs、60×60、4000K、酒店改造项目 [客户原文]
- 要求 CIF Dubai [客户原文]
- 提到当地消防安全要求 [客户原文]
- 我司主做 LED 面板灯 OEM，MOQ 1000 [公司上下文]

**推断**
- 客户可能处于供应商初筛或项目报价阶段 [依据：要 ASAP 报价 + 规格仍粗]
- “local fire safety”可能指向特定市场标准，但不能从“中东”直接推断具体标准编号 [依据不足]

**未知**
- 功率/光通量/驱动电源/调光要求 → 决定 BOM 与成本
- 具体要满足哪份消防/建筑标准 → 决定测试与能否接单
- 包装、交期、是否接受我司现有平台方案还是全新开模

### 当前最大阻塞

1. **产品规格不足以核价**（只有尺寸与色温）
2. **目标合规标准未明确**（消防要求可能是硬边界）

### 下一步最小有效动作

1. 回复：确认品类匹配；问 3 个会改价/改可行性的问题：①功率与光通量目标 ②是否有指定标准/检测报告要求 ③要现有方案改型还是全新开模
2. 内部：查现有 60×60 平台是否接近；合规同事确认“中东酒店消防”通常要哪些文件（标为需验证，不写成已确认法规）
3. 暂不报 CIF；可说明“规格确认后给出 FOB + 运费结构，避免 CIF 一次性空报”

### 现实验证

| 未知 | 谁验证 |
|---|---|
| 光/电规格 | Customer |
| 目标标准编号 | Customer + Public/Web（标准文本） |
| 现有平台是否可改 | Internal / Technical Staff |
| 运费与保险 | Forwarder |

### 承诺边界

**现在可以说**：品类匹配；MOQ 1000，2000 pcs 量级可谈；可协助整理常见出口文件路径。

**暂时不能承诺**：CIF Dubai 单价；一定通过某国消防认证；交期；开模费用。
