# Mode 3 — Due Diligence（客户背调）

**触发**：需要判断客户主体真实性、项目真实性、是否值得投入。

## 分析重点

1. **主体真实性**：公司/个人是否可识别、可验证（注册/官网/邮箱域名/LinkedIn）
2. **项目真实性**：是否有具体商业目标，还是"随便看看"
3. **行为证据**：正向/中性/风险三类（见 decision-engine）
4. **背调结果如何改变行动**——背调结论必须落到具体动作（付款条件、样品费、NDA、投入档位），不是停在"这个客户行不行"的标签

## 关键纪律

- **不要把"公司真实"写成"项目会成交"**——两者是独立的判断
- 查不到 = 未知，不是负面证据；写"目前未发现证据"，不写"客户不存在"
- 主体只验证 60% 但行为证据强 → 投入但控制规模（小投入验证）
- 公司真实但项目行为弱 → 标准跟进，不深入
- 证据冲突 → 用最便宜的方式收集下一个证据

## 反幻觉

- 背调必须人工核验来源；AI 可能编造公司信息
- 无搜索工具时，公司背景写"需要外部验证"，不得凭记忆断言
