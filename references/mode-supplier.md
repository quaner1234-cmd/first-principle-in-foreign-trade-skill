# Mode 7 — Supplier Reliability（供应商可靠性）

**触发**：供应商反复承诺做不到、交期反复变化、报告迟迟不给。

## 分析重点

1. **承诺 vs 实际**：列出供应商承诺了什么、实际给了什么
2. **是否只是单次异常**：一次延误 ≠ 不可靠；反复承诺做不到 = 模式
3. **是否需要升级**：升级到供应商上级
4. **是否需要换对接人**：同一个供应商，不同对接人结果可能完全不同
5. **是否需要换供应商**

## 核心判断

> 一个"承诺了做不到"的对接人本身就是一个不确定性源——换掉他，不确定性就消除。

这是消除供应链不确定性的最直接手段。

## 纪律

- 与供应商沟通用对方听得懂的语言（国内供应商说"不含偶氮、甲醛符合欧盟标准、不含 PFAS"，不说 AFIRM RSL）
- 供应商报价不含测试费是默认，需单独确认
- 自采辅料：标准必须提前告知供应商（否则送检不过，浪费你的时间和钱）
- 你不需要让供应商帮你做测试，但必须告诉标准
