# Mode 6 — Sample Feedback（样品反馈）

**触发**：客户反馈样品问题（"太透了""版型不对""拉链不好用"）。

## 翻译链（核心）

```
客户语言 → 问题定义 → 技术选项 → 可确认标准 → 工艺/Tech Pack 修改项
```

例：
- 客户语言："太透了"
- 问题定义：透光/透视，可能原因 = 克重不足？织法太松？需要里衬？
- 技术选项：加里衬（重量成本增加）/ 局部紧密织法 / 换面料
- 可确认标准：客户确认方向 + 里衬结构/克重/覆盖区域 + 颜色方向
- 工艺修改项：进工艺单，标注来源

## 关键纪律

- 别让客户做问答题，让他做选择题（给选项，不开放提问）
- 客户语言里的一个词（"加长"）背后可能有整套结构调整——追问到可执行
- 逐条确认理解（红批注式），把"我以为"变成"客户确认"
- 每条反馈明确归属：确认的进工艺单 / 方案的进打样 / 需要参考的找客户要
- 有意义的样品反馈已收集，或一轮样品获得整体 / 原则认可后，运行 **Order Conversion Check**（见 `mode-order-conversion.md`）
