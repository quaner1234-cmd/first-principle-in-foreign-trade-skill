# Mode 2 — Follow-up / Silence（跟进与沉默）

**触发**：客户不回复、回复慢、或需要判断是否继续跟进。

## 分析重点

1. **有没有新增证据**：客户上次回复后，有没有新的行为（点开链接？又发了邮件？）
2. **列出仍需验证的无恶意解释**（不得写成事实或无依据概率）：
   - 时区差异 / 工作量大 / 邮件进垃圾箱 / 出差度假 / 同时评估多家供应商
3. **是否有合理跟进理由**：每次联系必须有一个具体理由（"你上次问的样品照片准备好了"），不是"在吗？考虑得怎么样？"
4. **判断等 / 跟 / 降级 / 停止**：
   - 之前行为证据强（发过视频、寄过样）→ 「忙/出差」可作为 Candidate Explanation；继续等或有理由地温和跟进
   - 从没提供过实质信息 + 两周不回复 → 只可判断当前动量弱；降低投入或降频，不把「没兴趣」写成已知事实

## 关键判断

> 不要只看"不回复"这个行为本身，要看他在回复之前做过什么。

## 停止 vs 放弃

- 停止跟进 ≠ 放弃关系：结构性不匹配就降频率，等对方先动
- 关闭询盘（明确不匹配）→ 明确原因、礼貌告知、记录归档
