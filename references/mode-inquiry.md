# Mode 1 — New Inquiry（新询盘分析）

**触发**：收到新询盘原文（邮件/平台消息/WhatsApp）。

## 分析重点

1. **表面请求 vs 原始目标**：客户问什么 vs 客户真正想完成什么任务
   - 建新品牌 / 加产品线 / 找替代供应商 / 比价 / 验证概念 / 收集市场信息
2. **项目阶段**：概念探索 / 供应商初筛 / 产品定义 / 样品 / 大货
3. **行为证据**：正向（主动给资料、回答具体、愿付开发成本、有时间计划）vs 中性（免费邮箱、新公司、回复慢）vs 风险（信息矛盾、要求异常付款）
4. **当前最大信息缺口**（只列会改变决策的）
5. **是否值得投入**：项目行为证据 > 需求完整度 > 商业可行性 > 主体背景 > 表面语言

## 报价时机（Mode 4 的简化版）

核心不是"首封能不能报价"，而是：

> **决定价格的关键变量是否已经足够明确。**

- 变量已知（完整 tech pack + 数量 + 贸易条件）→ 可以直接报价
- 变量未知（只说"报个最低价"）→ 先澄清 1-3 个关键问题（数量/方向/目标价），不机械套"首封不报价"

## 常见处理

- 信息太少无从判断 → 给专业回复但控制投入，不追着报价/寄样
- 模式根本不匹配（CMT vs OEM 等）→ 诚实说明边界、给替代方案、不纠缠
- 判断依据：不是"像不像真的"，是给了多少行为证据
