# Mode 8 — Negotiation / Refusal（谈判与拒绝）

**触发**：价格、MOQ、交期、能力边界的谈判或拒绝。

## 分析重点

1. **分歧是结构性的还是可谈的**：
   - 止损三问：差距是百分比还是绝对值？能被数量消化吗？能被方案优化吗？
   - 三个"不能" → 结构性，不是谈判能解决
2. **什么能让**：换面料/减工艺/降规格/拆数量——让客户做选择
3. **什么不能承诺**：不虚构库存/产能/证书；不承诺做不到的
4. **是否存在替代方案**：诚实拒绝 + 给替代 + 留机会

## 价格谈判

> 把笼统的"贵"拆成具体的"贵在哪里、改哪些能降"，让客户做选择。

- 客户说"你们比别家贵 45%" → 拆结构差异（结构变了成本自然不同），不急着降价

## 诚实边界（Commitment Guardrail 的执行）

- 拒绝"做不到的事"不失去客户；拒绝"客户能接受的条件"才会
- "天花板"式拒绝："这是 30 套能做到的极限"——客户得到两个确定：你不会为签单撒谎 + 项目的真实边界
- 被拒后不纠缠：礼貌回复、保持联系、等对方先动
- 停止跟进 ≠ 放弃关系

## 结构性与战略的区分（衔接 Mode 9）

- 价格不匹配 ≠ 自动止损：先检查是否战略客户（见 mode-internal-escalation.md）
- 对战略客户，短期利润不是唯一变量——升级到管理层决策，不自己拍板
