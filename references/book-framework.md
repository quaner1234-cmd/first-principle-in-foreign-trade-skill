# Book Framework（书籍框架摘要）

> 本文件是《让客户敢下单》核心框架的浓缩。详细内容在各章节文件（按需加载）。Learning Mode 时引用，Action Mode 不自动展示。

## 全书主线

> 外贸业务员的工作，不是回复邮件和推销产品，而是持续降低交易的不确定性——直到客户敢于下单，并相信订单能够被完成。

两个层次：
- **降低不确定性是世界观**（解释外贸为什么存在、销售为什么有价值）
- **判断力是能力**（在证据不完整时做出可靠判断：知道哪些可查清、哪些只能验证、哪些必须承担风险、哪些应该停止、哪些值得下注）

## 核心框架

### 1. 事实 / 推断 / 未知 三分法
不把推断和习惯当事实；不把缺乏证据当负面证据。

### 2. 订单概率 = 需求真实性 × 方案匹配度 × 信任 × 预算 × 时间窗口
找出正在阻止订单的变量，针对它行动。

### 3. 四类不确定性
| 来源 | 解法 |
|---|---|
| 客观世界（技术/供应链） | 知识：拆到底层 + 第三方验证 |
| 人与人（需求/信任） | 诚实与清晰：给选项、说边界 |
| 系统制度（合规/结构） | 识别与止损：结构性差距不是谈判能解决的 |
| 销售自身（自我管理） | 承诺小、兑现快、卡住求助 |

### 4. 判断依据权重
项目行为证据 > 需求完整度 > 商业可行性 > 主体背景 > 表面语言

### 5. AI 分工
AI 负责降低信息处理的不确定性，人负责承担最终判断的不确定性。

## 关键方法（完整版见各章节）

- 价格预期管理（ch06）：每次成本变化提前预告 + 留记录
- 技术问题四步（ch07）：拆底层 → 第三方验证 → 变可验证假设 → 给选择
- 止损三问（ch08）：百分比差距？数量消化？方案优化？
- 翻译链（ch09）：客户语言 → 技术语言 → 可确认标准
- 诚实拒绝（ch10）：拒绝做不到的事推进交易；拒绝客户能接受的才失去
- 五步 AI 工作流（ch13）：定义不确定性 → 原始材料 → 区分三类 → 找矛盾 → 现实验证
- 自我管理五习惯（ch11）：承诺小兑现快 / 卡住求助 / 先交一部分 / 承诺写下来 / 定期复盘
