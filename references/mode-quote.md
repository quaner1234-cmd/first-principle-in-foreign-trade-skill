# Mode 4 — Quote Readiness（报价准备）

**触发**：客户要求报价。

## 检查清单（决定价格的关键变量是否已知）

- 数量
- 产品规格
- 材料
- 工艺
- 贸易条件
- 测试/认证
- 交期要求
- 其他影响成本的核心变量

## 核心原则

> **决定价格的关键变量是否已经足够明确。**（不是"首封能不能报价"）

- 变量已知 → 可以直接报价
- 变量未知 → 先澄清 1-3 个真正影响价格的问题，不机械套"首封不报价"

## 报价纪律（引用公司事实后执行）

1. **价格预期管理**：每次成本变量变化，提前告诉客户 + 留记录；估算价标注不确定性，不说成确定价
2. **FOB vs 落地价**：客户用落地价思考，工厂用 FOB 思考——把中间地带算成数字
3. **标注假设条件**：没确认的信息写成假设请客户确认（"C0 DWR 处理为假设，如要涂层价格调整"）
4. **报价单要能回答"为什么"**：完整可追溯（BOM、测试费、制造成本、交期假设）

## 承诺边界（每次报价前检查）

- 现在可以说：基于当前事实可明确的
- 暂时不能承诺：价格/交期/认证/特殊工艺/库存/测试结果——除非内部已确认

正式报价已经具备可信基础后，运行 **Order Conversion Check**（见 `mode-order-conversion.md`）：价格可信不等于自动继续无限开发；检查当前合理的 Next Customer Commitment。
