# Output Contract（输出契约）

默认输出必须短——业务员应在 **20-40 秒内读完主要结论**。

## 模板

```markdown
## 当前判断

一句话说明现在应该：**推进 / 先澄清 / 内部核实 / 外部验证 / 等待 / 升级 / 降低投入 / 关闭**
并说明最核心理由。

## 事实 / 推断 / 未知

### 事实
只列真正影响判断的事实。带来源标签：
`[客户原文]` `[公司上下文]` `[技术包]` `[公开来源]` `[工具验证]`

### 推断
每条说明依据。例：
- ✅ 客户使用 IIIA、ballistic、stab-resistant 等专业术语，因此**可能**有相关产品经验，但目前没有足够证据确认其身份。
- ❌ 客户是专业防护装备行业买家。（无依据的断言）
- ❌ 诚意 70% / 成交概率 73% / 诚意中等。（禁止精确/模糊评分）

### 未知
只列会改变决策的重要未知。Unknown ≠ 负面。
不要因为 Unknown 很多就生成大量问题（提问上限 1-3 个）。

## 当前最大阻塞

1-2 个。

## 下一步最小有效动作

按优先级最多 3 项。每项是具体动作，不是"继续跟进"。

## 现实验证

| 未知 | 谁验证 |
|---|---|
| 客户最终数量 | Customer |
| 面料最低起订量 | Supplier |
| 是否能做该结构 | Technical Staff |
| 是否批准战略价 | Management |
| 当前英国法规 | Public/Web Source |

## 承诺边界

### 现在可以说
基于当前事实可以明确告诉客户什么。

### 暂时不能承诺
没有证据支持，不能承诺什么（价格/交期/认证/特殊工艺/库存/测试结果/法规符合性）。
```

## 客户回复（仅在用户要求时追加）

```markdown
## 客户回复
（完成内部判断后生成，直接可发送）
```

- 不重复客户已经明确说过的内容
- 只回答当前需要解决的问题
- 不虚构公司能力
- 未内部确认的内容不写成承诺
- 问题尽量控制在 1-3 个
- 公司已有明确答案的不重复向客户询问
- 语言：客户当前沟通语言（英文客户默认英文）
