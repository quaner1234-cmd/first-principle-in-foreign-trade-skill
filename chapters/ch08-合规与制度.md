# 第八章 合规与制度：结构性的不确定

## Core Idea
有些不确定性是结构性的——来自行业规则、品牌制度和成本结构，不是谈判技巧能消除的。识别它、诚实面对它，比假装能解决更专业。

## Frameworks Introduced
- **止损三问**（判断是不是结构性不匹配）：
  1. 目标价和成本结构的差距是百分比还是绝对值？差 5% 是谈判空间，差 37% 是结构问题
  2. 这个差距能被数量消化吗？测试费摊到 3000 件 vs 10000 件，每件成本差 3 倍
  3. 这个差距能被方案优化吗？换面料/减工艺/降规格——能；规格锁定——不能
  三个"不能"→ 承认项目不是现在能做的。止损不是失败，是把资源留给可能成交的项目

- **面对结构性差距的正确姿势**：识别（不是报价能力问题）→ 不硬承诺 → 成本透明摊开 → 被拒后不纠缠 → 诚实传达但留机会

## Key Concepts
- **AFIRM RSL 是标准不是认证**：限用物质清单，说"符合要求"不说"通过认证"；OEKO-TEX/GRS/bluesign 才是认证
- **测试费有结构可优化**：指定面料供应商自提供报告（不用你花钱）、自采辅料才送检、有现成报告在有效期内直接用
- **对国内供应商说人话**："不含偶氮、甲醛符合欧盟标准、不含 PFAS、重金属符合 REACH、pH 4.0-7.5"——比 AFIRM RSL 听得懂
- **组织的不确定性**：业务员掌握客户重要性，但信息没传到能决策的高层 = 战略机会流失。对内向公司也要消除不确定性（项目战略简报）

## Mental Models
- 客户也在制度里：他给的目标价来自品牌方成本核算，他自己未必能改——你说"做不到"是在帮他节省时间，不是对抗
- 合规知识是稀缺能力：大多数工厂不会处理，你会，这就是差异

## Anti-patterns
- **为进大客户的门承诺做不到的价格**：报了达不到的价格，客户下单后违约，失去的不只是订单，是整个关系
- **把结构性差距当谈判问题**：降价哀求、反复追问"多少价格能接受"——尊重对方判断，礼貌回复，等机会
- **忽视内部信息传递**：客户是战略级机会，公司高层不知道 = 组织不确定性没消除

## Worked Example
O 牌项目（国际运动品牌）：目标价 vs 成本结构差 37-42%。差距来源：AFIRM RSL 测试、LRSM 审计（$3000-3800）、指定面料/辅料、SMS 费用、AQL 1.0（抽样验收体系，极严的可接受质量水平）、TT 90 天账期。合规成本摊到小订单每件 3.7-3.8 美元，竞争对手摊到几万件几乎可忽略。诚实报价 → 被拒 → 不纠缠 → 几个月后客户主动回来谈其他品类。
