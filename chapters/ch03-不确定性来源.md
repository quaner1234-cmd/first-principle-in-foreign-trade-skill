# 第三章 不确定性从哪里来

## Core Idea
不确定性有四个来源：客观世界、人与人、系统制度、销售自身。识别不确定性属于哪一类，决定你该用知识、诚实、止损还是自我管理去处理。

## Frameworks Introduced
- **四类不确定性矩阵**：
  | 来源 | 核心命题 | 解法 |
  |---|---|---|
  | 客观世界（技术/供应链） | 不确定性可以被知识消除 | 拆到底层找"为什么"，第三方验证 |
  | 人与人（需求/信任） | 可以被诚实和清晰消除 | 给选项、说边界、不模糊 |
  | 系统制度（合规/结构） | 有些是结构性的 | 识别、诚实面对、止损 |
  | 销售自身（自我管理） | 销售本人是不确定性的一部分 | 承诺小、兑现快、卡住求助 |

## Key Concepts
- **拿错工具**：用查资料解决信任问题（客户不确定你懂不懂，你却花两周证明自己懂行）
- **客户内部的不确定性**：决策链、预算审批——联系人热情 ≠ 项目在推进
- **外部环境不确定性**：汇率、关税、物流——不能消除，只能对冲和预警

## Mental Models
- 面对客户问题问三句：有客观答案吗？（查知识）→ 是客户对我的看法吗？（沟通）→ 是规则/结构决定的吗？（识别止损）
- 分类是分析工具，不是本体论——复杂项目四类同时存在

## Anti-patterns
- **把结构性差距当谈判问题**：目标价和成本结构差 37%，谈判技巧改变不了
- **把信任问题当知识问题**：客户不信你，你继续发资料，方向错了
- **忽视销售自身的不确定性**：你拖延两周，客户感受到的风险升高

## Worked Example
O 牌项目（国际运动品牌）：
- 客观世界：面料/测试规格（可查）
- 系统制度：AFIRM RSL、AQL、审计、测试费摊到小订单 = 结构性
- 销售自身：报价拖延两周，客户 COO 电话质问
- 组织：客户重要性没传到公司高层（战略信息断层）
四类不确定性同时存在，每类用不同工具处理
