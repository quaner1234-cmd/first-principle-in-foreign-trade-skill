# 第五章 背调与判断：证据够了吗

## Core Idea
背调真正难的不是"查到了什么"，而是：**信息永远不完整，什么时候已经有足够证据可以行动？** 背调不是"查完再判断"，是"边查边判断，用行动产生新证据"。

## Frameworks Introduced
- **五件事（不是五十件事）**：主体是否可识别 / 需求是否具体 / 行为是否一致 / 项目处于什么阶段 / 和我方匹配度
- **行为证据权重**：项目行为证据 > 需求完整度 > 商业可行性 > 主体背景 > 表面语言
  - 正向：主动提供资料、回答具体、愿付开发成本、有时间计划、持续推进
  - 中性（不是负面）：免费邮箱、新公司、网站少、回复慢、同时联系多家
  - 风险：信息矛盾、拒绝提供信息、数量大要求少、要求免费开发、异常付款、主体反复变

## Key Concepts
- **证据不足时的三个问题**：
  - 主体只验证 60% 但行为证据强 → 投入但控制规模（小投入验证代替全投入赌一把）
  - 公司真实但行为证据弱 → 标准跟进，不深入（公司真实 ≠ 值得投入）
  - 两个证据冲突 → 冲突是信息，用最便宜的方式收集下一个证据
- **"证据不足时，行动本身可以产生新证据"**

## Mental Models
- 查不到 = 未知，不是负面证据；不写"客户不存在"，写"未发现足够证据"
- 背调结论必须转化为具体动作（付款条件、样品费、NDA、投入档位），不是停在标签上

## Anti-patterns
- **虚假精确评分**："成交概率 73%"是伪科学——变量没有完整数据，数字给你虚假确定感
- 用定性描述代替：成交条件尚未形成 / 早期机会 / 具备评估价值 / 有较强样品推进可能 / 接近采购阶段
- A/B/C/D 分级只能用于排序筛选（先看哪条询盘），不能用于预测成交

## Worked Example
V 公司（亚洲高尔夫品牌）：背调记录把"公司真实"和"项目停在资格确认"分开——公司真实是事实，但 CMT 模式冲突也是事实，不把前者推演成"值得全力投入"。
