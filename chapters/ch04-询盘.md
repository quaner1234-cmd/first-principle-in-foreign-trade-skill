# 第四章 询盘：客户想实现什么结果

## Core Idea
询盘不是一条消息，是一个项目的第一块拼图。识别客户的原始目标（比回答客户的问题更重要），通过行为证据判断。

## Frameworks Introduced
- **表面请求 vs 原始目标**：客户说"请报 MOQ"，背后可能是：建新品牌 / 加产品线 / 找替代供应商 / 比价 / 验证概念 / 收集市场信息
  - 如何：收集证据（邮件细节、公司背景、项目阶段、沟通方式），然后直接问
- **报价时机原则**：**当决定价格的关键变量仍未知时，不宜给出看似确定的报价**
  - 客户给了完整 tech pack + 数量 + 贸易条件 → 直接报
  - 客户只说"报个最低价" → 先澄清（数量？方向？目标价？）

## Key Concepts
- **行为证据**：客户录视频、剪面料寄样 = 强行为证据；说一百句"我很认真"不如一个动作
- **结构性不匹配**：CMT vs OEM 这种模式冲突，诚实说明、给替代方案、不纠缠

## Mental Models
- 让客户说话（视频、实物、具体痛点），从行为里收集证据
- 判断询盘值不值得深入，看它给了多少行为证据，不是看"像不像真的"

## Anti-patterns
- **首封不报价当铁律**：变量已知就该直接报，绕弯子反而是制造不确定性
- **硬接结构性不匹配**：先答应 CMT 再想办法，最后做不好或中途退出，成本更高
- **两种不该多花精力的询盘**：信息太少无从判断的（给专业回复但控制投入）；模式根本不匹配的（关闭询盘：明确原因、礼貌告知、记录归档）

## Worked Example
John 的四段视频（旧连体衣"像囚服"、蜱虫痛点、面料起球、迷彩计划）→ 从一句话询盘到清晰产品定义 → 二次样品、500 件、2027 上市。关键：让客户说话，从行为收集证据。
