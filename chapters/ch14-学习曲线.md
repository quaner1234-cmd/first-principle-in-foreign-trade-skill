# 第十四章 从新手到成熟：三种不确定性类型的学习曲线

## Core Idea
客户规模不是判断的依据——初创客户可能极其专业，大客户也可能给你模糊的需求。真正决定你该训练哪种能力的是项目的不确定性类型。三种类型都经历过，你就有了完整的判断力。

## Frameworks Introduced
- **三种不确定性类型 → 三种能力**：
  | 类型 | 特征 | 核心能力 | 案例 |
  |---|---|---|---|
  | 需求模糊 | 客户说不清要什么 | 定义需求（给选项、听行为证据） | John（北林户外） |
  | 技术问题 | 客户懂行业但缺产品/供应链知识 | 用知识消除不确定性（拆到底层+验证） | 马雷克（滑雪俱乐部） |
  | 制度约束 | 合规、审计、指定供应商、账期 | 识别结构性边界（止损三问） | O 牌项目 |
- **客户规模 ≠ 不确定性类型**：初创客户可能拿完整技术包来；大客户也可能给你模糊需求——判断依据是项目不确定性集中在哪

## Key Concepts
- **案例库（从经历到能力的转换器）**：每个项目结束写五句——发生了什么 / 我怎么判断 / 哪些是事实哪些是猜测 / 结果如何 / 重来会怎么做。5 张卡看到模式，10 张卡知道自己的边界
- **大客户粘性**：进入供应体系（审计/测试/打样）后替换成本极高——但粘性是你创造的，每次交付都是加减分
- **健康客户结构**：一两个大客户（稳定现金流+技术积累）+ 几个中小客户（分散风险）

## Mental Models
- 经历只是素材，复盘才是学习——不复盘，下一次遇到同类问题还是抓瞎
- 知识是双向的：客户比懂他的行业，你补他不懂的部分（材料/工艺/供应链），用他的行业场景解释你的技术方案

## Anti-patterns
- **按客户规模分配投入**：把初创客户当大客户（过度投入）或轻视（投入过少）——判断依据是行为证据，不是公司大小
- **为进大客户的门承诺做不到的价格**：失去的不只是订单，是整个关系
- **以为客户不懂你的领域、需要你教他**：马雷克比谁都懂滑雪，只是不懂中国供应链和高端材料

## Worked Example
三个案例构成学习曲线：John（需求模糊，训练定义需求）→ 马雷克（技术问题，训练知识消除不确定性）→ O 牌（制度约束，训练识别结构性边界）。同一套方法（事实/推断/未知、行为证据、诚实边界）在不同类型里反复使用。
